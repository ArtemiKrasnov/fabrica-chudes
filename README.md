# Фабрика чудес

Одностраничный сайт Пензенского отделения Российского детского фонда: React-фронтенд на JavaScript, Java API, дом из девяти проектных окон, формы донатов, звёзды донатеров, статичный отчёт и FAQ.

## Запуск

Установите зависимости:

```sh
npm install
```

Для Java API требуется JDK 21 или новее. Запустите backend в одном терминале:

```sh
npm run server
```

Запустите frontend в другом терминале:

```sh
npm run dev
```

Команда автоматически компилирует Java-классы и запускает встроенный HTTP-сервер на порту `3001`. Vite проксирует запросы `/api` на backend `http://localhost:3001`.

## Платежи

Интеграция работает в тестовом режиме: реальные средства не списываются. Записи звёзд хранятся локально в `server/data/` и не включаются в Git.
