# Фабрика чудес

Одностраничный сайт Пензенского отделения Российского детского фонда: дом из девяти проектных окон, формы донатов, звёзды донатеров, статичный отчёт и FAQ.

## Запуск

Установите зависимости:

```sh
npm install
```

Запустите backend в одном терминале:

```sh
npm run server
```

Запустите frontend в другом терминале:

```sh
npm run dev
```

Vite проксирует запросы `/api` на backend `http://localhost:3001`.

## Платежи

Интеграция работает в тестовом режиме: реальные средства не списываются. Записи звёзд хранятся локально в `server/data/` и не включаются в Git.
